The ERJ is equipped with 4 cabin doors. The main

Aircraft General
Cargo
The ERJ 175 is equipped with both forward (FWD) 
and aft cargo bays. The FWD cargo bay has fresh 
air circulation. Live animals or dry ice can be 
placed in the FWD only (but not animals and dry 
ice at the same time). 
SkyWest Operation: When verifying the CLR (Cargo Load 
Report), make sure that animals OR dry ice are in the FWD cargo bay
only (but not at the same time). Animals take precedence over dry ice 
unless the dry ice is packaged with human organs for transplant, urgent 
medical supplies, or blood shipment. Dry Ice is never allowed in the AFT 
cargo bay.

EICAS (Engine Indication and Crew Alerting System)
Provides the flight crew with a four-level alert messaging system (red, 
amber, cyan, and white) and are organized in order of priority. 
Warning (red) and Caution (amber) messages also generate an aural 
warning.
Messages with the higher priority precede other messages when 
shown simultaneously.
When more than one EICAS message appears at the same time, the 
crew performs the required checklists according to the following 
message priority: 
WARNING, 
CAUTION ,
ADVISORY,
STATUS.
When more than one EICAS message within a category appears at the 
same time, the crew analyzes and defines which one is dealt with 
first.
The MCDU displays some messages in the event of a failure of both 
MFDs and the EICAS.

root EICAS message, the procedure for the WARNING message 
must be performed first. 
If more than one root message is displayed at the same time or 
displayed together with a WARNING message, the priority order 
to be evaluated is:
WARNING messages;
ELECTRICAL BUSES;

Class A Fires
These are fires that occur in ordinary

water, or of solutions containing large

Class B Fires
These are fires that occur in flammable liquids, 
such as gas, paint, oil, grease, etc., where a 
blanketing or smothering action is desired to 
cut off the oxygen supply to the blaze. Using 
water on a fire of this type generally causes it to 
spread, thus creating an additional hazard.

Class C Fires
These are fires that involve electrical

electrocution of the person attempting to 
extinguish the fire. Never use water on this type 
of fire.

SkyWest Operation: Set REF A/I to ENG if 
encountering visible moisture before 1700 ft AGL and 
the OAT is 5-10⁰C.

Ice and Rain Protection System
Wing Anti-Ice Temperature
After takeoff, when climbing through 10,000 ft, the 
wing anti-ice system automatically performs a test. The 
wing anti-ice valve is opened and the slats are heated 
until the test is complete. 
Note: If after 10 minutes the airplane has not reached 
10,000 ft, this test is performed. 
SkyWest Operation: Expect to see EICAS messages “A-I 
WING VLV OPEN” climbing through 10,000 ft 
associated with this test. 

Ice and Rain Protection System
Wing Anti-Ice Valve
Opens to allow hot bleed air to flow to the slats. 
Operation is automatic. If REF A/I is set to ALL in the 
Takeoff Dataset, wing anti-ice will turn on during the 
takeoff roll (40 KTS wheel speed).
SkyWest Operation: Set REF A/I to ALL if encountering 
visible moisture before 1700 ft AGL and the OAT is 
below 5⁰C.

Ice and Rain Protection System
Crossbleed Valve
If an engine bleed source is unavailable, the crossbleed 
automatically opens. Both wing anti-ice systems can 
operate from one engine bleed source. 
SkyWest Operation: In an abnormal situation, follow 
QRH and monitor system. The synoptic page can be 
useful in understanding the system’s status. 

Ice and Rain Protection System
Wing Anti-Ice
The outer three (3) slats are heated. 
Note: The tail (vertical and horizontal stabilizer) do not 
have anti-ice capability. During initial aircraft 
certification testing, tail anti-ice was determined to be 
unnecessary. 
SkyWest Operation: On the walkaround, if ice was 
encountered in flight, expect to see residual ice on the 
inboard portion of the wing, wingtips, and tail.
