**The problem:** The Widget Builder was calling the developer's external server (`proxy.worldmonitor.app`) every time you tried to use it, asking "is this person allowed?" Your local instance was getting rejected because you don't have his server keys.

**The fix:** It added a `SELF_HOSTED` mode across the whole app:

- **Widget Builder** now skips the external permission check entirely when self-hosted. No more phoning home.
- **The relay server** (which generates widgets via Claude) skips all the key matching and auth gates when self-hosted. It just needs your Anthropic key to work.
- **Rate limiting** disabled — no point throttling yourself on your own machine.
- **Docker config** updated so everything defaults to self-hosted mode.

To activate it, you need to add one line to your `.env.local`:

```
VITE_SELF_HOSTED=true
```

Open nano again:

```
nano ~/worldmonitor/.env.local
```

Add that line under your Anthropic key, save, restart `npm run dev`, and the Widget Builder should work without that "PRO key rejected" error.
