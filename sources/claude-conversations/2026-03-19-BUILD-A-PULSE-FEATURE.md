Good question, Phelipe. So ChatGPT Pulse is a proactive feature that does asynchronous research overnight based on your past chats, memory, and connected apps, then delivers personalized visual summaries each morning — basically a daily briefing you didn't ask for but (ideally) find useful.

**Short answer: No, Claude doesn't have an equivalent feature right now.**

Claude does have a memory system (which you're already using heavily across your OSA workstreams), and it has deep research capabilities when you ask for them. But there's no proactive, unprompted daily briefing that runs in the background while you sleep and surfaces cards for you in the morning.

Here's how the closest Claude features compare:

**What Claude does have:**
- **Memory across conversations** — I retain context about you and your projects between sessions, so when you come back I'm already up to speed.
- **Deep Research** — on-demand, you can ask me to do comprehensive research on a topic and I'll go deep with multiple searches and synthesis.
- **Web search** — real-time info retrieval whenever you need it.
- **Projects** — which you're already using to segment context by workstream.

**What's missing vs. Pulse:**
- No autonomous overnight research
- No proactive "push" notifications or morning briefings
- No connected app integrations (Gmail, Calendar) that feed context passively

Honestly, for your use case — tracking private aviation market developments, monitoring charter pricing trends, keeping tabs on FAA/DOT regulatory changes for Loud Hawk content — a Pulse-style feature would be pretty valuable. But it doesn't exist on Claude yet.

If you want to approximate it, you could build a lightweight morning routine where you open Claude and run a standing prompt like "give me today's private aviation intelligence briefing" using web search. Not the same as fully autonomous, but it'd get you 80% of the way there.
